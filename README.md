# Trading Creator — Forex & Indian Market Price Action Hub

Live production web application connected to Firebase (`forex-trader-website`) featuring:
- Interactive 3D `<Lanyard />` Pass & 60fps Support/Resistance Bouncing Broker Arena
- Courses & Mentorship Plans Carousel, 3D Flip VIP Pass, and 3D Bookshelf Library
- Free 3D Trading Calculators (Lot Size, Position Risk, Pip Value, Indian F&O Brokerage, R:R)
- Copyable TradingView Pine Script v5 Strategies, Trading Quizzes, and 3D Circular Carousel Verified P&L
- Firebase Authentication (Google Sign-In/Sign-Up + Email/Password + Forgot Email/Password Recovery), Cloud Firestore Real-Time Sync, and Cloud Storage
